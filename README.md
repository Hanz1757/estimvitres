# EstimVitres

🇫🇷 Application Android pour laveurs de vitres : estime rapidement le **temps** et le **prix** d'un chantier. Outil de calcul — pas un devis officiel.

🇬🇧 Android app for window cleaners: quickly estimate the **time** and **price** of a job. calculation tool — not an official quote.

## 📥 Télécharger / Download
👉 **[Dernière version / Latest version (APK)](https://github.com/Hanz1757/estimvitres/releases/latest/download/EstimVitres.apk)**

## 📲 Installer / Install
🇫🇷
1. Télécharge l'APK sur ton téléphone.
2. Ouvre le fichier → autorise « Installer des applications inconnues » si demandé.
3. Installe. Les mises à jour s'installent par-dessus (données conservées).

🇬🇧
1. Download the APK on your phone.
2. Open the file → allow "Install unknown apps" if prompted.
3. Install. Updates install over the previous version (data kept).

## ✨ Fonctions / Features
🇫🇷 Estimation à l'heure, par fenêtre, par surface ou au forfait · catalogue de fenêtres, clients, fournisseurs, trajets, suppléments · HT/TTC, fourchette de prix, export PDF/CSV · 5 langues, thèmes, hors ligne.
🇬🇧 Hourly, per-window, per-surface or flat-rate estimating · window catalogue, clients, suppliers, travel, surcharges · excl./incl. VAT, price range, PDF/CSV export · 5 languages, themes, offline.
